## Methodology & IP reality check (important)

This server's outbound IP is heavily **bot-walled**. Live results this run:

| Engine | Status this run |
|--------|-----------------|
| DuckDuckGo HTML (`html.duckduckgo.com/html`) | Worked ~2 of ~10 attempts, then hard "anomaly" block |
| DuckDuckGo Lite | "anomaly" block immediately |
| Brave Search | CAPTCHA-walled (confirmed challenge page) |
| GitHub search HTML | One hit, then throttled to 0 |
| Startpage / Ecosia / Mojeek | Blocked / empty |
| **Direct host fetches** (curl to a specific site) | **Reliable** — all 18 tried succeeded |

So: search-engine crawling was mostly a dead end, but **direct fetches to
specific tool sites worked fine**. Approach used: (1) the 2 DDG queries that
got through, (2) mined the directory/awesome-list pages those surfaced, and
(3) **verified each candidate by fetching its own site** and grepping for
"api key" / "sign up" / "log in" language. Every claim below is from a live
fetch on 2026-07-22.
