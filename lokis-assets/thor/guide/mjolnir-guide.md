# Mjölnir Infrastructure — Guide

## Use case
Hardening your agency’s infra so stolen creds, broken workflows, and leaked keys stop costing you clients.

## Setup
1. Import `workflows/make-security-scan.json` in Make.
2. Add scanner APIs: Snyk, NVD, SSTI, crt.sh.
3. Route results to Notification, Ticket, and Lockdown queues.
4. Add a weekly report for borderline issues.

## Sales tip
Bundle with Hel’s judgment workflow for compliance; buyers love paired security + awareness products.

## Support
Founder pack adds quarterly review checklist and incident templates.
