Windmill vs n8n vs Node-RED: which automation engine fits your team

Every agency has a forge—somewhere the team hammers out workflows that should run without heroes. The question is which anvil to use. Let’s cut the legends and look at three real contenders: Node-RED (the old smith), n8n (the clever apprentice), and Windmill (the battle-hardened berserker).

Node-RED: the steady smith

  • Best for: IoT shops, hardware tinkerers, and teams who want a free, no-frills canvas that runs on a Raspberry Pi.
  • Pros: Lightweight, 4 000+ community nodes, MQTT baked in, deploys anywhere Node.js breathes.
  • Cons: JSON payloads can feel like reading Futhark; no native secrets manager; scaling beyond 100 concurrent flows needs extra tooling (Redis, Kafka).
  • Real-world: A client used Node-RED to glue 500 smart meters to a Grafana dashboard—zero code, zero cloud bill, zero drama.

n8n: the shape-shifter

  • Best for: Agencies that live in SaaS land (HubSpot, Slack, Airtable) and want a self-hosted Zapier with teeth.
  • Pros: 350+ native integrations, error workflows, manual triggers, and the ability to drop into JavaScript when the canvas gets cramped.
  • Cons: Memory creeps up as workflows grow; the execution engine keeps state between nodes, so long-running flows can bloat (our lore page on stateful vs stateless explains why this matters).
  • Real-world: Switched a 47-step onboarding flow from Node-RED to n8n in a weekend—same logic, half the nodes, and the team could finally read the damn thing.

Windmill: the berserker

  • Best for: Teams that already write TypeScript and want automation to feel like engineering, not Lego.
  • Pros: Script-first, Git-native, scales like a cloud service, secrets vault built in, and you can debug a failing step with the same tools you use for your app.
  • Cons: No visual canvas; business users will stare at YAML and weep. Self-hosting needs Kubernetes or a beefy VM.
  • Real-world: A fintech client replaced 12 cron jobs and a tangle of Python scripts with Windmill—same throughput, 90 % fewer alerts, and the devs actually enjoy maintaining it.

How to choose

Pick Node-RED if your stack is physical or your budget is zero. Pick n8n if you’re drowning in SaaS apps and need a canvas that non-devs can grok. Pick Windmill if your team already speaks code and you want automation that scales like a cloud service without the lock-in.

One last tip: spin up each tool with the same 3-step workflow (trigger → transform → notify). The one that feels like putting on a well-worn glove is the one you’ll still be using a year from now.

Takeaway: Node-RED is Mjölnir—reliable, but heavy. n8n is Loki’s dagger—sharp and adaptable. Windmill is Tyr’s sword—precise, for those who know the cost of every cut.
