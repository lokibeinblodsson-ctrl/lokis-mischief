# Loki's Mischief — Norse Automation Brand Site

A premium single-page brand site featuring **4 playable Norse-mythology browser games** and a **Make.com/n8n workflow template marketplace** for agency owners.

## 🎮 The Games

| Game | Character | Mechanic | 
|------|-----------|----------|
| **Chain Strike** | Fenrir the Wolf | Click-timing — break chains to free the wolf |
| **Serpent Memory** | Jörmungandr | Simon-says memory — recall rune sequences |
| **Soul Judgment** | Hel | Resource judgment — sort souls for the underworld |
| **Eight-Legged Sprint** | Sleipnir | Endless runner — dodge obstacles to reach Asgard |

Each game features a procedural canvas-drawn character portrait with animated elements and a "freed" state that triggers on victory.

## 🎨 Features

- **Canvas-drawn portraits** — procedural art for all 4 Norse characters with gradient shading, particles, and glow effects
- **Freed state system** — winning a game transforms the character (chains vanish, eyes glow, background shifts)
- **Dark Norse aesthetic** — premium dark theme with gold (#f59e0b) accents, brutalist card design
- **Single-file architecture** — everything (HTML, CSS, JS) in one self-contained file for easy deployment

## 🛠️ Built With

- Vanilla JS with Canvas 2D API for character rendering
- requestAnimationFrame-based animation loop (60fps)
- No external dependencies — fully self-contained

## 🚀 Deployment

Open `Lokis-Mischief-Site.html` in any modern browser. No build step, no server required.
